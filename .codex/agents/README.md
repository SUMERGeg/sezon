# Subagent role prompts

Эти файлы — ролевые спецификации для делегирования через Codex multi-agent/orchestration. Они не являются отдельными процессами сами по себе: главный агент выбирает нужную роль, передаёт ей конкретный вопрос и ожидаемый output.

Правила:
- по умолчанию reviewer-агенты работают read-only;
- каждый получает узкий вопрос;
- findings должны ссылаться на конкретные элементы кода/доков;
- не назначать двум агентам одновременное редактирование одинаковых файлов;
- финальную синтезацию делает основной агент.
