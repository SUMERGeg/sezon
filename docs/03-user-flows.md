# 03. User flows

## Flow A — быстрый выбор букета

1. Пользователь открывает главную.
2. За первый экран понимает, что это магазин цветов.
3. Переходит «Смотреть коллекцию».
4. Видит цену и масштаб карточек.
5. Открывает товар.
6. Выбирает размер M.
7. Цена и availability обновляются.
8. Добавляет в корзину.
9. Получает ненавязчивое подтверждение.
10. Переходит в корзину/продолжает смотреть.

Acceptance:
- ни один шаг не зависит от hover;
- кнопка add-to-cart недоступна для unavailable variant;
- focus не теряется после состояния добавления.

## Flow B — выбор по поводу

1. `/shop`.
2. Фильтр «Повод → День рождения».
3. Результаты обновляются.
4. Выбранный фильтр виден chip/text summary.
5. Пользователь добавляет ещё «Светлая гамма».
6. Получает 3–6 релевантных товаров.
7. Сбрасывает один фильтр или все.

Edge:
- 0 результатов → понятный empty state + «Сбросить фильтры».

## Flow C — вариант закончился

1. Открыт товар.
2. Размер S доступен, M недоступен, L доступен.
3. M остаётся видимым, но обозначен «нет в наличии».
4. При выборе M кнопка покупки disabled и объясняет причину.
5. Пользователь выбирает L, CTA снова доступен.

## Flow D — корзина переживает reload

1. Добавить product A / variant M / qty 1.
2. Добавить тот же variant ещё раз → qty 2.
3. Добавить product A / variant L → отдельная строка.
4. Reload.
5. Корзина восстановлена по IDs и quantity.
6. Цена пересчитана из текущего каталога, а не доверяется localStorage.

## Flow E — demo checkout с доставкой

1. Из корзины перейти в checkout.
2. Сразу увидеть demo disclosure.
3. Выбрать «Доставка».
4. Появляются date/time/address.
5. Выбрать demo date и slot.
6. Заполнить тестовые контакты.
7. Итог = товары + стоимость demo-доставки.
8. Нажать «Завершить демонстрацию».
9. Показать success state без номера реального заказа и без обещания доставки.
10. Контакты не сохраняются.

## Flow F — самовывоз

- при выборе самовывоза address скрывается;
- стоимость доставки = 0;
- показывается demo-локация только если она явно обозначена как пример;
- нельзя публиковать вымышленный фактический адрес реального бизнеса.

## Flow G — открытка

1. В товаре/корзине пользователь включает «Добавить открытку».
2. В checkout появляется поле текста.
3. Ограничение длины, например 180 символов.
4. Текст не попадает в localStorage.
5. После завершения demo очищается.

## Flow H — keyboard/mobile

- menu button: Enter/Space open, Escape close, focus return;
- filter drawer: focus trap, Escape, return focus;
- selectors: semantic radios/buttons;
- product gallery: swipe optional, но кнопки next/prev доступны;
- sticky CTA на mobile не перекрывает системные/контентные элементы.
